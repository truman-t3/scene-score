# Contributing / 参与贡献

Thanks for helping Scene Score become more useful and more visually precise.

## Good contributions / 适合的贡献

- A clearly documented photo-to-score result, with permission to share the source image.
- A focused improvement to the rhythm, rest, or source-faithfulness guidance.
- A correction to installation, translation, links, or examples.

## Before opening an issue or pull request / 提交前

1. Start from the latest release and say which agent or image model you used.
2. For a visual result, include the source image only when you can share it; otherwise describe the scene and the visible result.
3. State what should remain from the source and what visual relationship failed: beat, direction, density, rest, or accent.
4. Keep each pull request focused. Do not add images unless you own the rights or state their license and attribution.
5. Run the Skill validator and the relevant checks in [`evals/scene-score-evals.md`](evals/scene-score-evals.md) before asking for review.

## Style / 风格

Use plain language, preserve the photograph's specific subject, and avoid turning one successful example into a universal layout rule. Chinese and English documentation should describe the same behavior.
