# 场景乐谱（Scene Score）v0.1.0

**为场景记谱，让它本来的节奏变得可见。**

[English](README.md) · [Skill 指令](SKILL.md) · [转译规则](references/translation-grammar.md)

场景乐谱是一个 Codex Skill：它将照片中的光、运动、间隔、密度和留白，转译为仍然忠于原场景的当代艺术图像。

**当前版本：**`v0.1.0` —— 首个公开版本。

它不套用固定风格，而是先读取照片里已经存在的关系，再把它们显现为**拍点、延音、停顿与重音**。照片仍然是事实依据；图形成为它的乐谱。

```text
照片 → 阅读现场 → 命名节奏 → 重构结构 → 在缩略图下核验
```

## 什么构成场景乐谱

| 原则 | 含义 |
| --- | --- |
| 保留一个真实锚点 | 让特定的人、物、地点或关系仍可辨认。 |
| 转译，不装饰 | 每个主要图形都来自可观察的力量：斑马线、台阶、栏杆、地平线、阴影、风、水波或密度变化。 |
| 让留白承担节奏 | 雾、墙面、天空、水面与暗部都是主动的构图材料，而不是剩下的背景。 |
| 证明改动成立 | 至少两处来自原场景的结构性变化，要在缩略图下仍清楚可见；只调色或加纹理不算。 |

不出现字面化的音符或五线谱，也不预设米白背景、圆形、条带或拼贴模板。只有这张照片能为一个图形提供理由时，它才成立。

## 两种记谱方式

| 模式 | 适合什么情况 | 结果 |
| --- | --- | --- |
| **Score-led reconstruction（乐谱主导重构）** | 希望明显艺术化，同时保留场景身份。 | 真实照片锚点与两到三个源自原图的图形角色彼此咬合。 |
| **Amplified score（强化乐谱）** | 希望获得更强、更编辑化的画面。 | 一个来自原场景的几何关系放大到主导缩略图，改变原图的轮廓或空间分区。 |

## 运行条件

- Codex 或其他兼容的 Skill 运行环境。
- 用于读图与质量检查的图像查看能力。
- 用于最终转译的图像生成能力。

本包不含脚本、API Key、外部字体或下载的运行时资源。案例是为本仓库制作的原创本地测试素材。

## 安装

将仓库克隆到对应的 Skill 目录：

```bash
git clone https://github.com/truman-t3/scene-score-skills.git ~/.codex/skills/scene-score
```

在 Windows 中，对应文件夹通常是 `C:\Users\你的用户名\.codex\skills\scene-score\`。

如果 Skill 没有立即出现，请重启 Codex。

## 使用

上传一张照片后，可以这样说：

```text
请用 $scene-score 将这张照片转成场景乐谱。保留主体，识别拍点、延音和停顿，
并做成结构改动在缩略图下仍清楚的当代艺术图像。
```

如果希望效果更强，可以补充：`使用 Amplified Score 模式，让来自原场景的主结构一眼可辨。`

## 输出

Skill 会返回：

1. 一张完成转译的图像。
2. 一段简短说明：保留了什么、转译了什么。
3. 当项目需要保存成品时，返回最终生成提示词。
