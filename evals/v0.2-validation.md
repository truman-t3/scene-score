# v0.2 validation runs / v0.2 复测记录

These are reviewable example runs, not fixed output targets. The pass/fail criteria remain in [the evaluation set](scene-score-evals.md).

以下是可复看的示例运行，并非固定成图模板；通过条件仍以[评测集](scene-score-evals.md)为准。

## 01 · Rain street / 雨街

- Source / 原图：[`rain-street-source.jpg`](../examples/rain-street-source.jpg)
- Result / 成图：[`rain-street-v0.2-score.jpg`](../examples/rain-street-v0.2-score.jpg)
- Mode / 模式：score-led reconstruction
- Prompt intent / 提示词要点：保留雨伞行人、公交车、斑马线与左侧暖店；让斑马线的不等间隔扩展为拍点，并以一条沿街透视行进的蓝色路径连接行人与公交。
- Pass note / 通过依据：行人、公交、湿路面和店铺仍然可辨；斑马线在下半部形成可见的非等距节拍，蓝色路径把视线带向远处公交。

## 02 · Stair hall / 阶梯大厅

- Source / 原图：[`stair-hall-source.jpg`](../examples/stair-hall-source.jpg)
- Result / 成图：[`stair-hall-v0.2-bright-score.jpg`](../examples/stair-hall-v0.2-bright-score.jpg)
- Mode / 模式：amplified score
- Prompt intent / 提示词要点：保留上行人物、栏杆、窗洞、明亮混凝土与暖灯；只在若干真实踏步上放大出不等量的靛蓝节拍，并让栏杆继续成为一条方向线。
- Pass note / 通过依据：人物、台阶方向和栏杆可辨；蓝色节拍直接来自踏步又保留了大量浅色混凝土，暖灯仍是唯一的小重音，而不是只靠压暗画面。

## 03 · Misty ginkgo / 雾湖银杏

- Source / 原图：[`misty-ginkgo-source.jpg`](../examples/misty-ginkgo-source.jpg)
- Result / 成图：[`misty-ginkgo-score.jpg`](../examples/misty-ginkgo-score.jpg)
- Mode / 模式：score-led reconstruction
- Prompt intent / 提示词要点：保留右侧树干、湖面小船、远山与水线；让叶片、芦苇的密度成为聚散的拍点，以雾和偏移水线提供停顿与延音。
- Pass note / 通过依据：树干、小船、远山和湖线仍可辨；叶与芦苇呈现不均匀密度，水面的透明层与水平关系在缩略图中仍然成立。
